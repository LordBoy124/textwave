# TextWave

A simple Teams-style chat app where people can sign up, sign in, chat with friends, create groups, and share files or screenshots.

## Features

- Sign up and sign in
- Direct chat messages
- Group chat creation
- File and image upload
- Teams-like layout
- Local demo persistence using browser storage

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000
